What do &lt; and &gt; do?

&lt; is the HTML entity for the less-than symbol (<).

&gt; is the HTML entity for the greater-than symbol (>).

They are used to display < and > in your HTML page without confusing the browser, since < and > are also used for HTML tags.

Example: &lt;b&gt;Bold&lt;/b&gt; will display as: <b>Bold</b> instead of making the text bold.

About the target Attribute

The target attribute specifies where to open the linked document. It can be used in <a> (anchor) and <area> tags.

ValueDescription
_blankOpens the link in a new tab or window.
_selfOpens the link in the same tab or frame (default).
_parentOpens the link in the parent frame.
_topOpens the link in the full body of the window.

Example usage:

  • Open Example.com in new tab (target="_blank")
  • Open Example.com in same tab (target="_self")
